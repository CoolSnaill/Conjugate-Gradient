# Метод сопряжённых градиентов

Откройте `dist/index.html` в современном браузере. Готовый модуль WebAssembly уже в составе сайта. Для запуска не требуется установка зависимостей или локальный сервер.

В лаборатории можно редактировать систему `Ax = b` размером от 2 до 6, задавать начальное приближение, точность и лимит итераций. График и таблица показывают евклидову норму фактической невязки `b − Ax`.

Вкладка «Траектория» отображает итерации на линиях уровня квадратичной функции `f(x) = ½xᵀAx − bᵀx`. Центр линий уровня вычисляет решатель Fortran по разложению Холецкого. Для систем размером больше двух выберите две оси. При построении сечения остальные координаты фиксируются в минимуме, а приближения проецируются на выбранные оси.

## Интеграция с Fortran

- `fortran/cg.f` проверяет симметрию и положительную определённость матрицы, выполняет метод сопряжённых градиентов и записывает данные по итерациям.
- `dist/solver.js` передаёт матрицу и векторы через линейную память WebAssembly. Матрица записывается по столбцам, как ожидает Fortran.
- `dist/solver-binary.js` содержит готовый модуль WebAssembly. Встраивание в JavaScript позволяет открывать сайт прямо с диска.

## Пересборка решателя

Понадобятся Node.js, [f2c](https://www.netlib.org/f2c/) и Clang с поддержкой WebAssembly, например из [WASI SDK](https://github.com/WebAssembly/wasi-sdk). Поместите `f2c` и `clang` в PATH либо передайте пути к исполняемым файлам в переменных окружения `F2C` и `WASM_CLANG`. Задайте `F2C_INCLUDE` равным каталогу, в котором лежит `f2c.h`. По умолчанию используется `/usr/include`.

```sh
node fortran/build.mjs
```

Скрипт переводит исходник Fortran в C через f2c, компилирует полученный C в WebAssembly и обновляет файл `dist/solver-binary.js`.
